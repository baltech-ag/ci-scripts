# Use `client-id` input for GitHub App token

## Context
`actions/create-github-app-token@v3` deprecates the input `app-id`. Every
release-actions run shows the warning "Input 'app-id' has been deprecated
with message: Use 'client-id' instead." once per token step.

The action reads `client-id` and `app-id` into the same variable
(`core.getInput("client-id") || core.getInput("app-id")`) and uses it as the
JWT issuer. GitHub accepts the App ID or the Client ID as issuer, so the
current secret `BALTECH_BOT_ID` (App ID) also works with `client-id`.

## Changes
`.github/workflows/release-actions.yml`: in the 3 "Generate a token" steps,
rename the input `app-id:` to `client-id:`. The value stays
`${{ secrets.BALTECH_BOT_ID }}`.
