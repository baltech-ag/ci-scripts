# Bump GitHub Actions to current major versions

## Context
5 third-party actions in ci-scripts are one or more major versions behind.
The breaking changes do not apply to ci-scripts:
- checkout v7: blocks fork-PR checkout on `pull_request_target` /
  `workflow_run`; ci-scripts uses neither event.
- setup-python v7: removes the `pip-install` input; not used.
- cache v6: ESM migration only.
- download-artifact v7/v8: Node 24 (runner >= 2.327.1), error on hash
  mismatch, no unzip of non-zip files. The self-hosted runners run 2.338.2
  and already run download-artifact@v8 in ToolSuite builds.
- setup-uv v9/v10: `prune-cache` defaults to false, cache is off for
  `pull_request_target` / `workflow_run` / `release`. No major tag exists,
  so pin the exact version.

## Changes
- `actions/checkout@v6` -> `@v7` (all workflows)
- `actions/setup-python@v6` -> `@v7` (`release-actions.yml`)
- `actions/cache@v5` -> `@v6` (`release-actions.yml`)
- `actions/download-artifact@v5` -> `@v8`
  (`actions/append-artifact-versions/action.yaml`)
- `astral-sh/setup-uv@v8.0.0` -> `@v10.3.3` (`jira-android-build.yml`)
